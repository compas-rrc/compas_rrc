# API Reference

`COMPAS RRC` exposes everything from the top-level `compas_rrc` package, so a
single import is usually all you need:

```python
import compas_rrc as rrc
```

The reference is split in three parts:

* [Clients](clients.md) — connecting to ROS and talking to the robot.
* [Instructions](instructions.md) — the RAPID instructions available out of the box.
* [Custom instructions](custom_instructions.md) — calling your own RAPID procedures.
